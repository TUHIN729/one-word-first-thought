One word, the first that came to mind: **petrichor** — the scent of rain falling on dry earth. A whole weather memory in nine letters: surprising, vivid, and specific rather than safe filler. The program writes exactly that one word to `/output/entry.txt`, nothing else.

## Run it

```sh
node main.ts
```
